# Jackson JSON

Учебный Java-проект по сериализации и десериализации данных с использованием
Jackson.

## Стек

- Java;
- Maven;
- Jackson JSON.

Проект демонстрирует работу с моделями данных, JSON-представлением и настройкой
сериализации.

## Структура

- `pom.xml` — Maven-конфигурация;
- `src/main/java` — модели и примеры Jackson;
- `src/main/resources` — входные данные, если они используются примером.

## Запуск

```bash
./mvnw test
```

В Windows используйте `mvnw.cmd test`. Для запуска конкретного примера откройте
его класс с `main` в IDE и запустите приложение.
